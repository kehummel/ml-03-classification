# Project 03 - Classification Models using Decision Tree, SVM, and Neural Network

## Description
We used three different models to predict survival on the Titanic in three different cases: Case 1 was whether or not they traveled alone, Case 2 was their age, and Case 3 was both their age and family size. I ran all three cases through decision tree models and SVC models. Only case 3 was used for the neural network since it is the only two-dimensional case.
